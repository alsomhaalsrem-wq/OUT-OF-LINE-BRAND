# OUT OF LINE

Private working repository for the OUT OF LINE website.

Collections: **MORE RISK MORE رزق** and **THE CAPITAL**.

## Local preview

With Node.js installed, run:

```sh
node preview-server.cjs
```

Open http://127.0.0.1:4173/. No package installation or build step is required.

## Editing

- `index.html`: page content, collection links and image descriptions.
- `site.css`: responsive layout, colors and typography.
- `assets/campaign/`: final campaign photographs and 480px / 800px responsive versions.
- `assets/fonts/`: self-hosted display and Arabic fonts.

Campaign images are AI-generated composites based on the supplied brand and Tripoli references. Earlier drafts, unused source photographs and videos are excluded from this repository.

Mobile layout uses uncropped responsive images, lazy loading below the fold, touch-friendly links, native scrolling and reduced-motion support.

This repository stores the editable source. It does not configure a public website deployment.
